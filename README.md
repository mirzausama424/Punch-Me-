# Punch Me

**Punch Me** is a Swift-based iOS app that allows users to interact with the app by uploading images, playing sounds, and triggering animations. This app is designed using UIKit and AVFoundation to offer a dynamic user experience.

## Features

- **Image Upload**: Users can upload an image from their photo library or use the camera.
- **Image Animation**: Tap on the image to trigger an animation that shrinks and restores the image.
- **Sound Effects**: Play a predefined sound when the image is tapped.
- **UI Interaction**: Easy-to-use interface with interactive elements like image gestures and alert pop-ups.
